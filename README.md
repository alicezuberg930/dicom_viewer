# DICOM Viewer frontend

React 19 + TypeScript + Vite application using the same shadcn/ui Base Nova,
Base UI, and Tailwind CSS v4 foundation as `D:\Projects\rem\apps\web`.

## Development

```bash
bun install
bun run dev
```

## Checks

```bash
bun run build
bun run lint
bun run format:check
```

Add more shadcn components with:

```bash
bunx shadcn@4.2.0 add <component>
```
